# Runbooks

This directory contains operational runbooks for common tasks and incident response.

## Structure

Place runbooks here with descriptive names:
- `deploy.md` — Deployment procedures
- `incident-response.md` — How to handle production issues
- `database-migrations.md` — Running migrations safely

## Template

```markdown
# Runbook: [Title]

## When to Use
[Describe the scenario]

## Prerequisites
- [ ] Checklist item

## Steps
1. Step one
2. Step two

## Rollback
How to undo if something goes wrong

## Contacts
Who to escalate to
```
