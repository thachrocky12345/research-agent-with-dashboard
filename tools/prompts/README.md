# Prompts

Reusable prompt templates for AI interactions.

## Structure

Store prompt templates here with clear naming:
- `experiment-design.md` — Template for designing experiments
- `code-review.md` — Template for code review requests
- `debugging.md` — Template for debugging assistance

## Template Format

```markdown
# Prompt: [Name]

## Context
[Background information to include]

## Task
[What you want the AI to do]

## Constraints
[Any limitations or requirements]

## Output Format
[How the response should be structured]
```
