- Price is `adjclose` where the vendor wrote it, otherwise close times a forward-filled adjustment factor. Backward fill is not used. SPY's last adjclose is 2019-08-30 and QQQ's is 2018-06-14. The one-day return on those dates is ordinary (−0.59% and +1.01%). Later returns are raw close-to-close and miss dividends the vendor stopped recording.
- FRED `BAMLH0A0HYM2` has no observations on or before 2021-12-31. The current vintage starts 2023-10-30 and the series is not in ALFRED. Those four columns are dropped at assemble time. No substitute spread was used. HYG/TLT from 2014 is a price ratio, not an OAS.
- Breadth is the 400 `stock_data` names with the longest history that still print on 2024-09-27, shortlisted by `reltuples`. Earliest start is CAT on 1962-01-02. The 200th and 400th names both start on 2014-03-10. Only 24 of the survivors start before 2000. A day is blank unless 20 names have a valid reading, so the development window is not empty. Survivorship caveat: these are 2024 survivors, so breadth levels are biased up, and the level jumps when the 2014 names appear. Prefer changes.
- Causality: 20 development dates, seed 20261029, sets core, fred, breadth, etf, long, and full all match the full-sample row at 1e-9. No long feature has correlation above 0.5 with the next-day SPY return. `features_long.pkl` matches a fresh assemble. Manifest locked, 9 files, about 75 seconds. It was rewritten once after `evaluate_model.py` gained a drop of all-null columns.
